# Experience the World (beta)

A prototype web app that helps autistic children aged 5–12 explore real places through 360° photos before they visit.

- **Child view:** `index.html` — tap the white rings to read about each spot, hear a parent read it, and play the sounds.
- **Parent mode:** the Grown-ups button — record your voice for each spot.
- **Admin mode:** add `#admin` to the end of the link — add and edit hotspots and sounds.

Prototype only: hotspots, sounds and recordings are saved in the browser on each device.
